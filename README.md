# Fontroom

Thư viện font chữ tương tác, tối ưu cho GitHub Pages. Tìm font, lọc theo phong cách, thử câu mẫu, lưu font yêu thích và sao chép CSS.

## Chạy trên máy

```bash
npm install
npm run dev
```

## Triển khai

GitHub Actions tự build và triển khai khi có commit lên nhánh `main`. Trong repository, đặt **Settings → Pages → Build and deployment → Source** thành **GitHub Actions**. Trang sẽ có tại `https://canhhocit.github.io/font-text/` sau khi workflow hoàn tất.

Font mẫu được tải từ Google Fonts khi thẻ font xuất hiện trong màn hình.
